
\section{Impacto}
\label{sec:impacto}

GitHub presentó una degradación del servicio durante 24 horas y 11 minutos, desde el 21 de octubre de 2018 a las 22:52 UTC hasta el 22 de octubre a las 23:03 UTC. Algunas funciones mostraban información desactualizada debido a problemas de replicación en MySQL. Además, las entregas de webhooks y las compilaciones de GitHub Pages estuvieron suspendidas durante gran parte del incidente \cite{Warner2018}.

Durante la recuperación se acumularon más de 5 millones de eventos webhook y 80\,000 compilaciones de GitHub Pages. Aproximadamente 200\,000 entregas webhook caducaron y fueron descartadas. GitHub informó que no perdió datos de usuario, aunque tuvo que recuperar y conciliar escrituras pendientes. El informe no publica cifras de pérdidas económicas ni incumplimientos de SLA \cite{Warner2018}.
