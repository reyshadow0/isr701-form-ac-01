
\section{Impacto}
\label{sec:impacto}

GitHub presentó una degradación del servicio durante 24 horas y 11 minutos. Además, las entregas de webhooks y las compilaciones de GitHub Pages estuvieron suspendidas durante gran parte del incidente \cite{Warner2018}.

Durante la recuperación se acumularon más de 5 millones de eventos webhook y 80\,000 compilaciones de GitHub Pages. Aproximadamente 200\,000 entregas webhook caducaron y fueron descartadas. GitHub informó que no perdió datos de usuario, aunque tuvo que recuperar y conciliar escrituras pendientes. El informe no publica cifras de pérdidas económicas ni incumplimientos de SLA \cite{Warner2018}.
